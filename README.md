# বাঙালিয়ানা বাজার

বাংলাদেশের হাতে তৈরি জিনিসের বাজার। জামদানি শাড়ি, নকশি কাঁথা, মাটির কাজ,
বাঁশ আর বেতের জিনিস, পাটের ব্যাগ, রিকশা আর্ট আরো অনেক কিছু। এই সাইটের
সাজ পহেলা বৈশাখের মতো। রিকশা আর্টের রং, কাঁথার সেলাই, আলপনা, জামদানির
নকশা। সব ছবি হাতে আঁকা এসভিজি। কোনো ফটো নেই। কোনো ফাইল ডাউনলোড করা হয়নি।
তাই পুরো প্রজেক্ট শুধু লেখা ফাইল দিয়ে তৈরি।

## লেখার নিয়ম

এই সাইটের সব লেখা বাংলা। সহজ সরল বাংলা। ছোট ছোট বাক্য। কঠিন শব্দ নেই।
বাড়িয়ে বলা কথা নেই।

• সব লেখা বাংলা, সহজ সরল বাংলা।
• কোনো শব্দ মোটা নয়। সব লেখার ওজন ৪০০।
• কোনো লেখা বাঁকা নয়।
• শব্দ ভেঙে লাইন বদলায় না। সিএসএসে হাইফেন বন্ধ করা আছে।
• দাম বাংলা সংখ্যায় লেখা হয়। যেমন ৳৮,৫০০।
• ফন্ট: Baloo Da 2। এটা বাংলা হাতের লেখার মতো দেখতে, খুব জনপ্রিয় ফন্ট।
  গুগল ফন্টস থেকে আসে। শুধু ওজন ৪০০ লোড হয়। পড়তে সহজ রাখতে Hind Siliguri
  ফলব্যাক হিসেবে আছে। Kalpurush গুগল ফন্টসে নেই, তাই সেটা ব্যবহার করা হয়নি।

## ভেতরে কী আছে

• দোকান: Vite, React 19, TypeScript, Tailwind CSS 4, React Router।
  পাতা: হোম, বাজার, পণ্যের পাতা, কারিগর আর ঝুড়ি। ঝুড়ি থেকে অর্ডার এক পাতায়,
  চার ধাপে: ঝুড়ি, ঠিকানা, হিসাব, হয়ে গেল। নিচের রাস্তায় মামা ঝুড়ি মাথায় বাড়ি যান।
• সার্ভার: Node আর Fastify। ফোল্ডার server। কোনো ডাটাবেস নেই। কোনো লগইন নেই।
  পণ্য আসে data/products.json থেকে। অর্ডার জমা হয় data/orders.json এ।
• ঝুড়ি ব্রাউজারে জমা থাকে। সার্ভার না চললেও সাইট চলে। তখন বান্ডল করা
  পণ্যের তালিকা দেখায়। অর্ডার তখন ব্রাউজারে জমা হয়।

## পেমেন্ট: শুধু ক্যাশ অন ডেলিভারি, ডেমো

অর্ডার শুধু ডেমো। পেমেন্ট শুধু ক্যাশ অন ডেলিভারি। কোনো অনলাইন পেমেন্ট নেই।
কোনো পেমেন্টের কোড নেই। পণ্য হাতে পেয়ে টাকা দিতে হয়।

• ঢাকায় ডেলিভারি ৳৬০, সময় ২ দিন।
• ঢাকার বাইরে ৳১২০, সময় ২ থেকে ৪ দিন।

## কীভাবে চালাবেন

```bash
pnpm install

# টার্মিনাল ১: এপিআই, http://127.0.0.1:3001
pnpm server

# টার্মিনাল ২: দোকান, http://localhost:5173
pnpm dev
```

ভাইট ডেভ সার্ভার /api পাঠায় Fastify সার্ভারে। তাই ফ্রন্টএন্ড শুধু
/api/products আর /api/orders ডাকে।

বিল্ড:

```bash
pnpm build   # tsc আর vite build, ফল dist ফোল্ডারে
pnpm preview # বিল্ড করা সাইট দেখায়, http://localhost:4173
```

## এপিআই

• GET /api/health: সার্ভার চলছে কি না জানায়।
• GET /api/products: data/products.json এর সব পণ্য দেয়।
• GET /api/products/:id: একটা পণ্য দেয়, না থাকলে ৪০৪।
• POST /api/orders: নাম, ফোন, জেলা, ঠিকানা, জিনিস যাচাই করে। দাম নিজে
  হিসাব করে। পণ্যের দাম আর ডেলিভারি ফি যোগ করে। অর্ডার data/orders.json এ
  জমা করে। ফেরত দেয় অর্ডার নম্বর, মোট টাকা, ক্যাশ অন ডেলিভারি।
• GET /api/orders/:id: একটা অর্ডার দেয়, না থাকলে ৪০৪।

যাচাই: নাম কমপক্ষে ৩ অক্ষর। ফোন ০১ দিয়ে শুরু, ১১ সংখ্যা। ঠিকানা কমপক্ষে
৮ অক্ষর। কমপক্ষে একটা জিনিস লাগবে। পরিমাণ ১ থেকে ৯৯। ক্যাশ অন ডেলিভারি
ছাড়া অন্য পেমেন্ট দিলে ৪০০ ফেরত যায়।

## ফোল্ডারের গঠন

• data/products.json: পণ্যের তালিকা। এপিআই এখান থেকে পড়ে।
• data/orders.json: অর্ডার জমা হয়। শুরুতে খালি।
• server/index.js: Fastify এপিআই। সাধারণ জাভাস্ক্রিপ্ট। ডাটাবেস নেই।
• src/components: হেডার, ফুটার, পণ্যের কার্ড, পণ্যের ছবি (এসভিজি), কাঁথার সেলাই,
  আলপনা, মেলার দোকান, মামার রাস্তা।
• src/libs/mascot: মামা। আলাদা লাইব্রেরি, যেকোনো পাতায় বসানো যায়।
• src/data/products.ts: পণ্যের তালিকার কপি। সার্ভার না চললে এটা দেখায়।
• src/pages: হোম, বাজার, পণ্যের পাতা, কারিগর, ঝুড়ি (Jhuri.tsx)।
• src/data/districts.ts: ৬৪ জেলা। ঢাকায় ডেলিভারি ৳৬০, বাকি সব জেলায় ৳১২০।
• src/store/cart.tsx: ঝুড়ি আর পছন্দের তালিকা। ব্রাউজারে জমা থাকে।
• src/App.tsx: রাউটার। কোন পাতা কোথায় যায়, এখানে লেখা।
• src/index.css: রং, কাঁথা আর আলপনার নকশা, অ্যানিমেশন।
• index.html: ফন্ট লোড হয় এখানে। Baloo Da 2 আর Hind Siliguri।

## পণ্য কীভাবে যোগ করবেন

• src/data/products.ts এ পণ্য যোগ করুন।
• তারপর pnpm sync:products চালান। এটা data/products.json বানিয়ে দেয়।
  জেসন ফাইল হাতে বদলাবেন না।
• ছবির জন্য art বেছে নিন। যেমন jamdani, kantha, monipuri, terracotta,
  jhapi, bamboo, jute, rickshaw, gamchha, cushion, kansa, pitha, pati, diya।
  নতুন ছবি লাগলে src/components/ProductArt.tsx এ এসভিজি আঁকুন।
• দাম টাকায় লিখুন। যেমন ৮৫০০।

## অনলাইনে তোলা

দোকান যায় Vercel এ, এপিআই যায় Render এ।

• Render: New → Blueprint, এই রেপো বেছে নিন। render.yaml থেকে সব সেটিং আসে।
  চালু হলে ঠিকানাটা নিন, যেমন https://bangaliyana-bazar.onrender.com।
• vercel.json এ /api এর ঠিকানা যদি আলাদা হয়, Render এর ঠিকানা বসিয়ে পুশ করুন।
• Vercel: New Project, এই রেপো। Vite নিজেই চিনে নেয়। বিল্ড pnpm build, ফল dist।
• Render এর ফ্রি সার্ভার ১৫ মিনিট চুপ থাকলে ঘুমায়। প্রথম অর্ডারে এক মিনিট লাগতে পারে।
• ফ্রি সার্ভারে data/orders.json প্রতিবার নতুন করে চালু হলে মুছে যায়।
  আসল অর্ডার রাখতে হলে Render এর ডিস্ক বা একটা ডাটাবেস লাগবে।
• নিজের কম্পিউটারে সার্ভার না চললে অর্ডার ব্রাউজারে জমা হয়। অনলাইনে তা হয় না,
  তখন ভুলের কথা দেখায়, যাতে কেউ ভুল করে ভাবেন না যে অর্ডার হয়েছে।
