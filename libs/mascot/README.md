# মাসকট লাইব্রেরি

এই লাইব্রেরিতে বাঙালিয়ানা বাজারের মাসকট আছে। ঝুড়ি মাথায় হাঁটা মানুষ, আসল ছবির মতো দেখতে। যেকোনো পাতায় এটা ব্যবহার করা যায়, আবার লিখতে হয় না।

## কিভাবে ব্যবহার করবেন

1. মাসকট আনুন
2. যেখানে দরকার, সেখানে বসান

উদাহরণ

```
import { Mascot, MascotWalker, stageForProductCount, moodForEarning } from '../../libs/mascot'

<Mascot mood="happy" stage="half" walking={true} />
<MascotWalker mood="happy" stage="half" direction="right" walking={true} />
```

ঝুড়ির ভরা অবস্থা পণ্যের সংখ্যা থেকে নেওয়া যায়

```
const stage = stageForProductCount(4)
```

মন বসানো যায় টাকা এলো কি না, সেই হিসাব থেকে

```
const mood = moodForEarning(true)
```

## Mascot এর props

1. mood: খুশি বা মন খারাপ। খুশি মানে সামনে এগোনো, মন খারাপ মানে টাকা না আসা।
2. stage: ঝুড়ি কতটা ভরা। খালি, একটু ভরা, অর্ধেক ভরা, প্রায় ভরা।
3. direction: বামে বা ডানে। বামে হাঁটলে মুখ বামে ঘুরে যায়।
4. walking: সত্যি হলে পা নড়ে, শরীর দোলে। মিথ্যা হলে দাঁড়িয়ে থাকে।
5. speed: কত জোরে হাঁটে, পিক্সেল প্রতি সেকেন্ড। সাধারণ মান ১১০।
6. width: কত বড় দেখাবে। সাধারণ মান ২৪০।
7. className: বাড়তি সাজ দরকার হলে।
8. alt: ছবির বাংলা বর্ণনা।

## MascotWalker এর props

Mascot এর সব props এর সাথে আরও তিনটি আছে।

1. startPosition: শুরুর জায়গা, ট্র্যাকের কত শতাংশ থেকে শুরু করবে। সাধারণ মান ৮।
2. onWalkEnd: কিনারায় পৌঁছালে এই কাজটা চলবে।

## ছবি

ছবিগুলো assets ফোল্ডারে আছে। শরীরের চারটি ছবি, ঝুড়ির চার অবস্থার জন্য। মুখের মন খারাপ ছবি আলাদা। পায়ের দুটি ছবি আলাদা করে নড়ে। আসল ডিজাইন বদলানো হয়নি, শুধু নড়াচড়ার জন্য যতটুকু দরকার, ততটুকু ভাগ করা হয়েছে।

## সাজ

সাজের ফাইল mascot.css। রং বেইজ, নিচে আলপনার ফোঁটার মাটি। হাঁটার সময় পা নড়ে, শরীর দোলে। ফোনে কম নড়াচড়া চাইলে, সেটিংস মানলে নড়াচড়া বন্ধ হয়ে যায়।
